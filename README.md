# Cine_BookDB

A cinema ticket booking database system built with SQL. This project stores and manages cinema booking data such as movies, shows, customers, and bookings.

## 📁 Project Structure

```
Cine_BookDB/
├── CineBook_Database System/
│   ├── CineBookDB_Presentation.pptx   # Project presentation slides
│   └── cine_sql.sql                   # SQL queries
└── README.md
```

## 🗄️ Database

- **Database name:** `cinemabookingdb`
- The booking details are stored in the `booking` table.

### Sample Query

```sql
SELECT * FROM cinemabookingdb.booking;
```

## ▶️ How to Use

1. Open MySQL Workbench / phpMyAdmin / any SQL client.
2. Import or run the SQL scripts from `cine_sql.sql`.
3. Select the database:

```sql
USE cinemabookingdb;
```

4. Run the queries to view bookings and other data.
